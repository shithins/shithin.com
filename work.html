II Work — software & tools 11.2588° N / 75.7804° E

Sovereign software, built to endure.

Products, browser extensions and experiments incubated under theblackit and shipped to live users. No venture deck, no growth loop — just tools that remove friction.

01–04 — The Index Four products, in the order they were built
01 theblackit An independent product studio founded in Kerala. Community-first software designed to eliminate unnecessary SaaS friction. Launching 2026 ↗ 02 Clockroach A lightweight time-logging tool and Chrome extension for engineering teams and freelancers. Client-side cloud sync, zero tracking lag. Live · clockroach.work ↗ 03 Brain Crawl A gamified new-tab extension serving daily micro-quizzes on technical SEO, Core Web Vitals and search algorithm updates. Live · Chrome Web Store ↗
04 Keeptime Attendance and HRM living inside a browser extension, on a bring-your-own-data Google Sheets architecture. Clocking, breaks and leave approval without a per-seat fee. Pilot · Private —

Made for people who are tired of renting software.

The common thread in all of it: the tool should cost what it costs, own what it stores, and disappear when the job is done. Vanilla JavaScript where a framework would only add weight. Manifest V3 extensions that respect the browser they live in.

Some are products, some are fixes to my own problems. All of them ship.
